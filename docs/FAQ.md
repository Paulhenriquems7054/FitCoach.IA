# ❓ FAQ - Perguntas Frequentes

## 📋 Geral

### O que é o FitCoach.IA?

O FitCoach.IA é uma plataforma completa de gestão nutricional e fitness com inteligência artificial. Oferece:
- Planos alimentares personalizados
- Análise de refeições por foto
- Chat de texto e voz com IA
- Planos de treino personalizados
- Sistema de academias (B2B2C)

### O app é gratuito?

O app oferece um **trial de 3 dias grátis** com acesso completo às funcionalidades de IA. Após o trial, é necessário assinar um plano para continuar usando.

### Quais são os planos disponíveis?

**Planos Individuais:**
- Monthly (mensal)
- Annual VIP (anual)

**Planos B2B (Academias):**
- Starter Mini
- Starter
- Growth
- Pro


---

## 🎁 Trial

### Como funciona o trial?

O trial oferece **3 dias grátis** com acesso completo, mas com limites:
- **Voz:** 5 minutos por dia (total de 15 minutos)
- **Análise de imagem:** 1 análise durante todo o trial
- **Chat de texto:** Ilimitado

### Quem recebe trial?

- ✅ Alunos que se cadastram via código de convite da academia
- ✅ Usuários que se cadastram sem código (indicados)
- ❌ Personal Trainers
- ❌ Donos de academia

### O que acontece ao final do trial?

Ao final dos 3 dias, o acesso às funcionalidades de IA é bloqueado. Você precisará assinar um plano para continuar usando.

## 💳 Pagamentos

### Quais formas de pagamento são aceitas?

Aceitamos pagamentos via **Cakto**, que aceita:
- Cartão de crédito
- PIX



### Como cancelar minha assinatura?

1. Acesse sua conta
2. Vá em **Configurações** → **Assinatura**
3. Clique em **Cancelar Assinatura**
4. Sua assinatura continuará ativa até o final do período pago

### Posso reembolsar?

Entre em contato com nosso suporte para solicitar reembolso. Analisaremos cada caso individualmente.

## 🏋️ Sistema de Academias

### Como funciona o sistema de academias?

Academias podem:
- Criar convites para alunos
- Gerenciar alunos (bloquear/desbloquear)
- Acompanhar progresso dos alunos
- Personalizar configurações

### Como me cadastrar como aluno de uma academia?

1. Solicite um código de convite da sua academia
2. Acesse o app
3. Clique em **Usar Código de Convite**
4. Digite o código
5. Complete seu cadastro

### Posso ser aluno de múltiplas academias?

Não, cada usuário pode estar vinculado a apenas uma academia por vez.

## 🤖 Funcionalidades de IA

### Como funciona o chat de texto?

O chat de texto permite conversar com a IA sobre nutrição, treinos e saúde. Basta digitar sua pergunta e receber respostas personalizadas.

### Como funciona o chat de voz?

O chat de voz usa **Gemini Live** para conversas em tempo real. Você fala e a IA responde por voz. Funciona como uma consultoria nutricional por voz.

### Como funciona a análise de imagem?

Tire uma foto da sua refeição e a IA analisará:
- Calorias
- Macronutrientes (proteínas, carboidratos, gorduras)
- Sugestões de melhoria
- Informações nutricionais

### Quantas análises de imagem posso fazer?

- **Trial:** 1 análise durante todo o trial
- **Planos individuais:** Conforme limite do plano
- **Planos B2B:** Conforme limite do plano da academia

## 🔧 Problemas Técnicos

### O app não carrega

**Soluções:**
1. Limpe o cache do navegador (Ctrl+Shift+Delete)
2. Tente em outro navegador
3. Verifique sua conexão com a internet
4. Tente em modo anônimo

### Erro "API key not valid"

**Solução:**
1. Verifique se você está usando a versão mais recente do app
2. Limpe o cache do navegador
3. Se o problema persistir, entre em contato com o suporte

### Erro "Supabase não configurado"

**Solução:**
Este é um erro de configuração do servidor. Entre em contato com o suporte.

### Chat de voz não funciona

**Soluções:**
1. Verifique se seu navegador suporta microfone (Chrome, Edge recomendados)
2. Permita acesso ao microfone quando solicitado
3. Verifique se não atingiu o limite diário de voz
4. Tente em outro navegador

### Análise de imagem não funciona

**Soluções:**
1. Verifique se a imagem está nítida
2. Certifique-se de que a refeição está visível na foto
3. Verifique se não atingiu o limite de análises
4. Tente novamente após alguns segundos

## 📱 Dispositivos

### O app funciona em mobile?

Sim! O app é uma **PWA (Progressive Web App)** e funciona perfeitamente em dispositivos móveis. Você pode:
- Acessar via navegador
- Instalar como app (menu do navegador → "Adicionar à tela inicial")

### Quais navegadores são suportados?

**Recomendados:**
- Chrome (desktop e mobile)
- Edge (desktop e mobile)
- Safari (iOS)

**Funcionam, mas com limitações:**
- Firefox
- Opera

### Os dados ficam salvos no meu dispositivo?

Sim! Os dados são salvos localmente no seu dispositivo usando **IndexedDB**. Isso significa que:
- ✅ Dados persistem mesmo após fechar o navegador
- ✅ Funciona offline (dados locais)
- ✅ Dados não são perdidos ao atualizar o app

## 🔒 Privacidade e Segurança

### Meus dados são seguros?

Sim! Utilizamos:
- **Criptografia HTTPS** para todas as comunicações
- **Row Level Security (RLS)** no banco de dados
- **Armazenamento local** para dados sensíveis
- **Conformidade com LGPD/GDPR**

### Vocês vendem meus dados?

Não! Nunca vendemos ou compartilhamos seus dados pessoais com terceiros.

### Posso deletar minha conta?

Sim! Você pode deletar sua conta a qualquer momento em **Configurações** → **Privacidade** → **Deletar Conta**.
