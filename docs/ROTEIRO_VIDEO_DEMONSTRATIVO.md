## 🎬 SEQUÊNCIA DE GRAVAÇÃO SUGERIDA

### **Ordem de Captura:**
1. **Dashboard e navegação geral** (base para transições)
2. **Chat por texto** (mais simples de gravar)
3. **Chat por voz** (requer áudio limpo)
4. **Análise de imagens** (preparar prato realista)
5. **Planos de treino** (dados pré-configurados)
6. **Biblioteca de exercícios** (scroll suave)
7. **Análise de progresso** (gráficos pré-populados)
8. **Funcionalidades avançadas** (comunidade, desafios)
9. **B2B (se aplicável)** (dashboard de academia)

### **Dicas de Captura:**
- Use ferramentas como OBS Studio ou Camtasia
- Grave em 60fps para suavidade
- Use cursor personalizado (se disponível)
- Evite cliques muito rápidos
- Faça pausas entre ações para facilitar edição
- Capture áudio separadamente
